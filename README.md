## Projects

### 1. Linux Account Management Automation

Python-based automation for common Linux account administration tasks.

**Features:**

* Check Linux account status
* Unlock locked accounts
* Reset user passwords
* Reset failed login attempts
* Support for `faillock` and `pam_tally2`
* Command-line arguments using `argparse`
* Error handling
* Post-action verification
* Activity logging

Example:

```bash
python3 account_management.py --user pytestuser --action unlock
```
